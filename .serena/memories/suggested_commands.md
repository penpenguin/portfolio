# Suggested Commands

- `npm install` – install dependencies.
- `npm run dev` – start Astro dev server (http://localhost:4321/ by default).
- `npm run build` – build static site into `dist/`.
- `npm run preview` – serve built site for smoke-testing.
- `npm run test` – run Vitest unit tests (jsdom/testing-library ready).
- `npm run check` – run `tsc` then `astro check` for types/content schema.
- `npm run format` – Prettier (with Astro plugin) fix formatting across repo.
